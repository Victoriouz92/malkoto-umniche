# Каталог с образователни механики

> **Генериран файл.** Не го редактирай — промените се губят при следващото
> пускане на `npm run build:mechanics`. Данните са в `0*.json` в тази папка.

105 механики за деца 2–8 г., подредени по образователна стойност.

Каталогът НЕ е код. Той е основата, върху която се пишат активностите:
всяка бъдеща активност посочва механиката, която реализира, и наследява
от нея умения, възрастов обхват и правила за достъпност.
