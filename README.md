# Малкото Умниче

Сайт: [umniche.vvlabs.eu](https://umniche.vvlabs.eu)

Безплатна образователна PWA за деца 2–6 години. Без реклами, без абонаменти,
без заключено съдържание. Работи офлайн. Всичко се пази на устройството —
няма бекенд и няма акаунти.

> **Състояние: кандидат за публично издание.** 27 двигателя, 543 активности, 20 звука и три фонови мелодии, родителски панел с
> PIN и лимити, албум със стикери. Работи офлайн.
> Одитът и границите на проверката са в [docs/RELEASE-AUDIT-2026-11-12.md](docs/RELEASE-AUDIT-2026-11-12.md).

## Команди

```bash
npm run check
```

Пълната проверка: типове → lint → валидация на съдържанието. Върти се
автоматично преди `npm run build`.

| Команда                    | Действие                                                                        |
| -------------------------- | ------------------------------------------------------------------------------- |
| `npm run dev`              | Дев сървър                                                                      |
| `npm run build`            | `check` + продукционен build                                                    |
| `npm run test:browser`     | Playwright срещу продукционния build; изисква `npx playwright install chromium` |
| `npm run test:games`       | Изиграва всяка от 543-те активности до завършване                               |
| `npm run preview`          | Преглед на build-а (тук service worker-ът е активен)                            |
| `npm run typecheck`        | Само TypeScript                                                                 |
| `npm run lint`             | Само ESLint                                                                     |
| `npm run validate:content` | Само активностите                                                               |
| `npm run icons`            | Прегенерира PWA иконите                                                         |
| `npm run format`           | Prettier                                                                        |

Браузърните тестове изиграват всяка активност с профил на началната ѝ възраст
чрез докосване и клавиатура при 390 px. Проверяват правилни и неправилни
ходове, подсказки, завършване, повторен старт и запазения резултат след
презареждане. Допълнителен обход проверява зареждането офлайн при 320 px.
Виж [каталога по възраст](docs/EXPANDED-LIBRARY.md).

## Правила, които кодът налага сам

Не са пожелания — счупването им вдига червен build.

**Никакви твърди цветове.** ESLint блокира всеки hex литерал в `.ts`/`.tsx`.
Цветовете живеят единствено в `tokens.css`.

**Активност за деца до 4 г. е задължително `noFail`.** Zod схемата отказва
активност с `ageMin ≤ 4` и `noFail: false`. Принцип 2 от [PLAN.md](PLAN.md) е
записан в схемата, не оставен на добрата воля.

**Активност не може да изисква едновременно звук и цветово зрение.** Твърде
много деца отпадат от такава комбинация.

**Името на файла = `id` на активността.** Валидаторът сверява и двете, плюс
уникалност и съществуване на всеки ключ от речника.

**Български интерфейс.** Игровият речник и имената на активите са централизирани в i18n. Публичната помощ и част от родителския интерфейс са директно на български; не се обещава готов превод на втори език.

## Дизайн системата

Витрината на `/#/ds` е инструмент, не демо. Показва:

- всички цветови токени в двете теми (смени темата на ОС — компонентите не
  знаят нищо за цветове)
- превключвател на **възрастовата лента**: `toddler` / `preschool` / `school`
  сменят `--tap`, `--tap-lg` и отстоянията, а компонентите растат сами
- вариантите на бутоните, включително плътния долен ръб, който потъва при
  натискане (Juicy Feedback, точка 1)
- трите вида панели, сред тях и **устойчивият** — този, който детето не може
  да отхвърли (мек стоп, PIN врата)
- празнуването с конфети, което мълчи при `prefers-reduced-motion`

### Възрастови ленти

| Лента       | Възраст | `--tap` | `--tap-lg` |
| ----------- | ------- | ------- | ---------- |
| `toddler`   | 2–4 г.  | 88px    | 112px      |
| `preschool` | 5–6 г.  | 72px    | 88px       |
| `school`    | 7–8 г.  | 56px    | 72px       |

Общият токен е `--tap-min: 48px`. Компактните точки за очертаване имат минимум 44px и отделна проверка срещу застъпване при 320px; картите се побират според наличния екран.

### Червено няма

В детския режим няма цвят за „грешка". Мекото връщане ползва `--c-gentle`
(лилаво) — забележимо, но неосъдително. `--c-danger` съществува само за
родителския панел.

## Готовност за публикуване

Подробности: [одит за изданието](docs/RELEASE-AUDIT-2026-11-12.md).

Статичен сайт без платени API, бекенд, акаунти, аналитика или покупки. Началната страница се генерира като четим HTML при build. Помощ, поверителност и атрибуция са достъпни публично. Техническите витрини са само в development.

Родителят може да изтегли и възстанови профилите и напредъка от JSON копие. Гласовите записи не са включени. При проблем с IndexedDB има възстановяване или изричен временен режим. Записите се пазят като двоични данни за съвместимост с WebKit; старите Blob записи продължават да се четат.

PWA се обновява по избор извън играта; друга започната игра не се презарежда. Началната страница показва кога файловете са готови за офлайн работа.

27 двигателя, 543 активности, 20 MP3 звука, три генерирани мелодии. Оригиналните Ogg файлове са запазени. За прегенериране на MP3 е нужен ffmpeg или FFMPEG_PATH.

600 браузърни сценария се изпълняват отделно за Chromium, Firefox и WebKit в GitHub Actions. Резултатите от конкретния комит се прилагат към PR и изданието. Лабораторна проверка не е сертификация или тест на физически телефони.

За хостване: npm run build и статичните файлове от dist върху HTTPS. Vercel използва vercel.json за защитни заглавки; има GitHub Pages workflow за безплатно хостване на публичното хранилище. Публичният адрес трябва да сервира проверения комит преди обявяване на новото издание.
