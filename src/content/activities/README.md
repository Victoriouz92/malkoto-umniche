# Активности

Тук живее съдържанието на „Малкото Умниче“. Един JSON файл = една активност.

**Още е празно.** Първите активности идват в T4.3, след като двигателите от
T4.2 съществуват.

## Правила, които валидаторът налага

| Правило | Защо |
|---|---|
| Името на файла = `id` | Файл се намира по id без търсене |
| `id` е уникален | Дублирано id мълчаливо би скрило едната активност |
| `titleKey` и `parentNoteKey` съществуват в `src/i18n/bg.ts` | Липсващ ключ показва самия ключ пред детето |
| `ageMin ≤ 4` изисква `noFail: true` | Принцип 2 от PLAN.md |
| Не може едновременно `requiresAudio` и не-`colorIndependent` | Твърде много деца отпадат |
| Всеки asset е регистриран в манифеста | Липсваща картинка = празно квадратче в играта |

Провери с:

```bash
npm run validate:content
```

## Ключовото правило

Нова активност = **нов JSON**. Ако добавянето ѝ изисква да пипнеш код, значи
ти трябва нов двигател — не хак в стар. Това е разликата между платформа,
която стига до 500 активности, и такава, която засяда на 60.
